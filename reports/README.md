# Rapports JSON

Ce dossier centralise les rapports JSON générés par les scripts d’audit, de test et d’export.

## Types de fichiers déplacés

- `*report*.json`
- `*results.json`
- `*export.json`

## Objectif

- Garder la racine du dépôt propre
- Regrouper les artefacts d’exécution dans un emplacement unique
- Faciliter la revue et l’archivage des résultats
